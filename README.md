# 💊 Smart Pharmacy Management System

A modern web application for pharmacy inventory and sales management.

## 🚀 Overview
This system helps pharmacists track medicine stock, manage sales, and monitor expired products through a simple, responsive dashboard.

## 📸 Screenshot
![Screenshot](static/img/desktop.png)

## ✨ Features
- **Live Inventory**: Track medicine quantities and prices.
- **Sales Tracking**: Process customer sales with prescription verification.
- **Expiry Alerts**: Identify expired products instantly.
- **Responsive UI**: Works on Desktop, Tablet, and Mobile.

## 🛠️ Tech Stack
- **Backend**: Flask (Python)
- **Database**: MySQL
- **Frontend**: HTML5, CSS3, JavaScript

## 🏃 Quick Start
1. **Clone the repository**:
   ```bash
   git clone https://github.com/Khaled-Alabadla/smart-pharmacy.git
   ```
2. **Install dependencies**:
   ```bash
   pip install flask mysql-connector-python
   ```
3. **Database Setup**:
   - Log in to your MySQL workbench.
   - Run the commands in `database.sql` to create the database and tables.
   - (Optional) Update `db_config.py` with your MySQL credentials (user, password).
4. **Run the server**:
   ```bash
   python app.py
   ```
5. **Open the app**:
   Go to `http://127.0.0.1:5000`
